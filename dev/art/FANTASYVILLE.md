# Fantasyville 에셋에서 넣은 그림 (v54)

사용자가 구매한 Fantasyville 유료 에셋(사용 허가 확인)에서 잘라 넣었어요. 모두 `.raw.png`(그린 그대로, 게임 테두리 없음)예요.
원본 시트는 저장소에 올리지 않고, 잘라 낸 조각만 넣었어요.

| 게임 그림 | 가져온 곳 |
|---|---|
| 흙 바닥 `floor/2` (8장 섞임) | 동굴 팩 모래색 바닥 2종 + 마을 팩 작은 돌멩이 |
| 이끼 바닥 `floor/1` (10장 섞임) | 마을 팩 잔디 2종 + 풀포기·작은 꽃 |
| 나무 바닥 `floor/5` | 실내 시트 나무 마루 |
| 돌 바닥 `floor/6` | 실내 시트 돌벽돌 바닥 |
| 흙벽 `wtop/1`, `wfront/1` | 동굴 팩 바위 절벽 |
| 횃불 | 동굴 팩 불꽃 횃불 |
| 초록 말랑이 | 동굴 팩 슬라임 (주황·보라·용암·얼음 말랑이는 같은 그림을 게임 원래 색으로 다시 칠함) |
| 구리·철·금광석, 석영, 돌, 서리 결정, 구리·철·금괴 | 동굴 팩 광석·주괴 |
| 구리·철·황금·수정 곡괭이, 구리·철 망치, 구리·철 도끼, 삽, 구리·철·황금·수정 검, 물뿌리개, 낚싯대, 수정결정 | 대장간 팩 도구 |
| 작업대 / 구리 제작대 | 대장간 팩 공구 작업대 / 모루 |
| 2인 소파(가로·세로), 큰 책장, 부엌 조리대, 꽃병, 요리솥 | 실내 시트 |
| 나무 의자(앞·옆·뒤), 화분 | 식료품점 팩 |
| 둥근 나무, 그루터기, 이끼풀, 이끼 바위, 나무 상자, 전기 램프 | 마을 팩 |

광맥 벽은 사용자가 직접 그릴 예정이라 넣지 않았어요. 보물상자·큰 러그·침대·마을 집처럼 우리 게임 칸보다 훨씬 큰 그림은 뺐어요.
