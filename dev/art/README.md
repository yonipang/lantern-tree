# 직접 그린 16px 그림

여기에 게임 안 경로 그대로 PNG를 넣고 `python3 dev/art_pack.py`를 실행해요. 자세한 규칙은 `dev/README.md`의 「16px 그림」.

- 한 칸 = 16×16px, 그림 아래쪽 끝 = 땅에 닿는 곳, 가장자리 1px은 비워 두기
- 외곽선·바닥 그림자는 그리지 않기 (게임이 옛 그림과 같은 테두리를 붙임). 그린 그대로 쓰려면 `이름.raw.png`
- 바닥·벽 그림 넣는 법은 `dev/README.md`의 「16px 그림」, Fantasyville에서 넣은 그림 목록은 `FANTASYVILLE.md`
