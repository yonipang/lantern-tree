- 관련: [기획-결정사항.md](./기획-결정사항.md), 지금 코드 상태는 [등불나무-최신게임현황.md](./등불나무-최신게임현황.md)

## 1. 왜 하나

- 멀티플레이 전에 넣어요. 멀티플레이에서는 바닥이 바뀌는 일을 모두 같이 보내야 하므로, 먼저 만들어 두면 멀티 단계에서 같은 방식으로 맞추면 돼요.
- 건축의 재미를 넓혀요. 해자·연못·길 막기를 만들 수 있고, 바닥을 원하는 재료로 바꿀 수 있어요. 기획 가이드의 탐험·전투·건축 연결과 맞아요.

## 2. 바닥 파기·메우기·교체 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 느낌 | 코어키퍼처럼 블록을 지우거나 바꾸는 느낌 |
| 삽 | **바닥만 파요.** 지금의 「덤불 퍼내기」(열매 덤불·작물 퍼 옮기기)는 없애요 |
| 판 칸 | **구덩이**가 돼요. 사람·몬스터는 못 지나가고, 화살·마법 같은 발사체는 지나가요 |
| 메우기 | 구덩이에 바닥 재료(흙 한 삽·이끼 한 삽 …)를 놓으면 메워져요 |
| 교체 | 바닥 위에 다른 바닥을 깔면 바뀌고, **원래 바닥은 돌려받아요** |
| 깐 바닥 | 직접 깐 바닥(나무 바닥·돌 바닥·물 타일 …)도 삽으로 걷으면 그 아이템을 돌려받아요 |
| 못 파는 곳 | 보스방, 등불나무 둘레 9칸, 물·용암 칸, 벽 칸, 물체가 있는 칸, 누가 서 있는 칸 |
| 갇혔을 때 | 바닥을 메우거나 긴급 탈출을 써요. **구덩이에 둘러싸인 것도 「갇힘」으로 봐요** (긴급 탈출 조건) |
| 그림 | 구덩이 그림은 코드로 만들어요 (지형 그림 예외와 같이). 그림을 따로 받지 않아요 |
| 멀티플레이 | 다른 칸 바뀜과 똑같이 모두에게 보내요 |

## 3. 나무·열매·자연 재생 【확정 기획】

- **나무·열매 덤불·자연 나무는 베거나 따면 바로 없어지고 다시 자라지 않아요.** (지금은 그루터기·덤불이 남아 다시 자라요)
- 대신 벤 나무·딴 열매는 **씨앗이나 묘목을 꼭 1개** 줘요. (지금 자연 나무 묘목은 22% 확률)
- **세계 자연 재생은 실제 시간 하루에 하나**: 자연물이 새로 생기는 건 실제 시간으로 하루에 한 개만. (지금은 플레이어 가까이에서 3초마다 풀·뿌리 기둥이 자랄 수 있어요)
- **이끼풀·빛버섯·들꽃이 같은 자리에서 다시 자라는 것은 그대로** 둬요.
- **모든 자연물은 사용자가 직접 깐 「건축」 바닥 위에서는 자라지 않아요.**
- 나무 재료는 **묘목 심기와 나무 작업장(벌목장)**으로 얻어요. 코어키퍼의 나무 얻는 방식처럼요. 나무 작업장은 지금처럼 다시 자라요.

## 4. 물·용암 흐름 【확정 기획】

- 물은 **이어진 구덩이로 흘러요.** 한 칸씩 퍼져 나가고, **원래 물은 줄어들지 않아요.**
- 물이 찬 칸은 낚시할 수 있고, 걸어갈 수 없고, 바닥 재료로 메울 수 있어요.
- **용암도 흘러요.** (용암 흐름 세부는 아래 5-2)

## 5. 양동이 【확정 기획】

- 새 도구 **빈 양동이**: 물 칸에 대고 쓰면 「물 한 동이」를 하나 얻어요. **물 칸은 줄어들지 않아요.**
- 받는 「물 한 동이」는 지금 있는 아이템 그대로예요. 수프·분수·스프링클러 재료로도 그대로 써요.
- 「물 한 동이」는 **구덩이에만 부을 수 있어요.** 부으면 물이 차고, 이어진 구덩이로 흘러가요. (지금은 아무 빈 땅에나 부으면 웅덩이가 생겨요)
- **삽은 이제 물을 못 떠요.** 물 뜨기는 양동이로만 해요. (지금은 삽으로 물을 뜨면 그 칸이 흙이 돼요)
- **용암은 뜰 수 없어요.**
- 만들기: **작업대, 나무 4 + 구리 막대 1.** 지금의 「물고기 10마리 낚으면 물을 배워요」 조건은 **양동이 레시피를 여는 조건**으로 옮겨요.
- **닳지 않아요.**

## 5-1. 바뀌는 지금 동작 (구현할 때 확인)

| 지금 (코드) | 바뀐 뒤 |
|---|---|
| 삽으로 덤불·작물·그루터기 퍼내기 (`sim/actions.js`) | 없앰 |
| 삽으로 물 뜨기 → 칸이 흙이 됨 (`world/tiles.js` `digGround`) | 양동이로만, 물 칸 그대로 |
| 삽으로 이끼·버섯흙·수정바닥 뜨기 → 칸이 흙이 됨 | 파면 구덩이가 됨 (흙도 파짐) |
| 「물 한 동이」 아무 빈 땅에 붓기 | 구덩이에만 |
| 나무·덤불 다시 자람 (150초·240초) | 바로 사라지고 씨앗·묘목 1개 |
| 플레이어 가까이 3초마다 풀·뿌리 기둥 | 실제 시간 하루에 하나 |

## 5-2. 구현 전에 정한 것 【확정 기획】 (2026-10-17 사용자 선택)

| 항목 | 정한 것 |
|---|---|
| 판 바닥에서 얻는 것 | **「배워야 옮길 수 있음」 조건을 없애고, 판 바닥은 모두 그 바닥 한 삽**: 흙 → 흙 한 삽, 이끼 → 이끼 한 삽, 버섯흙 → 버섯흙 한 삽, 수정바닥 → 수정바닥 한 삽, 재 바닥 → **재 한 삽**, 눈 바닥 → **눈 한 삽** (새 아이템) |
| 얼어붙은 물(얼음판) | 팔 수 있어요. 파면 새 아이템 **「얼음 한 삽」**이 나오고, 그걸로 다른 곳에 얼음판을 깔거나 구덩이를 메워요 |
| 흐름 빠르기 | 한 칸 퍼지는 데 **물 0.5초 · 용암 2초** |
| 물과 용암이 만나면 | 만난 칸이 **돌 바닥**(걸을 수 있음)으로 굳어요 |
| 흘러 들어온 칸의 떨어진 물건 | **용암은 태워 없애요**, 물은 옆 빈 칸으로 밀어내요. 몬스터는 구덩이에 못 들어가서 상관없어요 |
| 하루 하나 새 자연물 | **세계 아무 곳**(그 지역에 맞는 빈 자연 바닥), 게임을 안 한 날 몫은 **최대 7개까지 쌓였다가** 다음에 들어올 때 생겨요 |
| 옛 세이브 | 이미 있는 그루터기·자라는 중인 덤불은 **그대로 한 번 다 자란 뒤** 다음부터 새 규칙. 물 뜨기를 배운 세이브(물고기 10마리)는 양동이 레시피가 바로 열려요 |
| 그림 | 구덩이는 코드로 그려요. 빈 양동이 아이콘은 **물 한 동이 그림을 임시로** 쓰고, 그림 1장이 필요해요 |

## 6. 「한 삽」 없애기 — 흙·얼음은 벽·바닥 같은 재료 【확정 기획】 (2026-10-18 사용자 선택)

흙벽을 캔 「흙」과 바닥을 판 「흙 한 삽」처럼 같은 흙이 두 아이템으로 나뉘어 헷갈리던 것을 합쳐요.

| 항목 | 정한 것 |
|---|---|
| 합치기 | **흙 한 삽 → 흙**, **얼음 한 삽 → 얼음 덩이**. 하나로 벽도 쌓고 바닥도 메우거나 바꿔요 |
| 짝이 없는 바닥 재료 | 이름에서 「한 삽」만 빼요: 이끼 한 삽 → **이끼 흙**(이끼 섬유와 다른 물건), 버섯흙·수정 모래·재·눈 |
| 들고 누르면 (기본) | 흙·얼음 덩이를 들고 빈 바닥을 누르면 **벽 쌓기**(지금과 같음). 구덩이를 누르면 **메우기** |
| 보조 버튼 | 흙·얼음 덩이를 들고 있으면 상호작용 옆 작은 버튼에 **바닥 쌓기(구덩이 메우기) 또는 바닥 바꾸기**가 나와요 |
| 건축 모드 | 흙·얼음 덩이는 건축 목록 **「벽」 탭과 「바닥」 탭에 둘 다** 보이고, 바닥 탭에서 고르면 메우기·자연 바닥 바꾸기 |
| 밸런스 | 지금 흙 2 → 흙 한 삽 2(1:1)라 그대로. 손 제작 「흙 한 삽」은 없애요. 레시피 재료 「이끼 한 삽」은 「이끼 흙」으로 이름만 바뀜 |
| 옛 세이브 | 가방·상자·떨어진 물건의 흙 한 삽·얼음 한 삽은 **같은 개수의 흙·얼음 덩이**로 바꿔요 |

**v93에서 구현** (2026-10-19). 큰 버튼·작은 버튼은 위 표대로, 건축 모드 「벽」 탭은 벽 쌓기만(구덩이 메우기는 「바닥」 탭에서).

## 7. 파기·바꾸기 크기 고르기 【확정 기획】 (2026-10-23 사용자 선택)

지금은 삽도 바닥 바꾸기도 바라보는 1칸씩만 돼요. 넓은 연못·길을 만들 때 오래 걸려서 크기를 골라 쓰게 해요.

| 항목 | 정한 것 |
|---|---|
| 크기 | **1칸 · 2×2 · 3×3 · 4×4** 중에서 골라요 |
| 바꾸는 법 | 삽이나 바닥 재료(흙·이끼 흙 …)를 들면 상호작용 옆 **작은 버튼에 「1×1」**. 누를 때마다 1 → 2 → 3 → 4 → 1로 돌아요. PC는 키 하나도. **고른 크기는 기억**해요 |
| 쓰는 곳 | **삽으로 파기·걷기**, 그리고 바닥 재료로 하는 **메우기·바닥 바꾸기**가 같은 크기를 따라요 |
| 자리 | **내 앞으로 뻗어요**: 바라보는 칸부터 앞으로 N줄, 가로는 바라보는 칸이 가운데. 내 발밑·옆 칸은 안 건드려서 구덩이에 갇히지 않아요. 2×2·4×4는 한쪽으로 한 칸 더 |
| 미리 보기 | 누르기 전에 **바뀔 칸을 테두리로** 보여 줘요 |
| 내구도 | 삽은 **판 칸 수만큼** 닳아요(4×4로 16칸이면 16). 얻는 재료와 닳는 양이 1칸씩 팔 때와 같아요 |
| 빠르기 | 크기와 상관없이 **한 번 누르고 다음까지 0.22초**(지금 1칸과 같음) |
| 건축 모드 | 건축 모드에 「파기」는 **넣지 않아요**(놓기·옮기기·뜯기·되돌리기 그대로). 건축 모드 바닥 탭 네모 끌기도 그대로 |

**v137에서 구현** (2026-10-23). 구현 때 Claude가 정한 것(사용자 확인 대기 — 플레이하다 고칠 것이 있으면 그때):
- 못 하는 칸은 **건너뛰고** 되는 칸만. 누른 칸 자체가 안 되면 지금처럼 까닭 알림
- **누른 칸과 같은 일만**: 자연 바닥을 파면 깐 바닥은 안 걷고(반대도), 메우기는 누른 칸과 같은 것(구덩이·물·용암)만, 바닥 바꾸기는 자연 바닥만
- 바닥 재료가 모자라면 **가진 만큼, 바라보는 칸에 가까운 칸부터** + 알림 「○○이 모자라서 N칸만 했어요」. 삽은 남은 내구도만큼만
- 흙·얼음 덩이로 **벽 쌓기는 1칸**, **물 한 동이 붓기도 1칸**, 손에 안 든 삽의 자동 [걷기]도 1칸
- 짝수 크기는 **오른쪽(위아래를 볼 때)·아래쪽(좌우를 볼 때)**으로 한 칸 더, PC **X 키**, 흙·얼음 덩이는 작은 버튼 「바닥 바꾸기」 다음 칸이 크기
- 고른 크기는 캐릭터마다 저장(옛 세이브는 1칸), 미리 보기는 2×2부터(1칸은 예전처럼 안 그림)

예전 【검토 중】 목록(정할 때 쓴 것):
- 범위 안에 못 파는 칸(벽·물건·누가 선 칸·보스방·등불나무 둘레·워프 둘레 …)은 **건너뛰고** 되는 칸만. 한 칸도 안 되면 지금처럼 까닭을 알림
- 바닥 재료가 모자라면 **가진 만큼, 바라보는 칸에 가까운 칸부터**
- 흙·얼음 덩이로 **벽 쌓기는 1칸 그대로**(크기는 바닥 일에만), **물 한 동이 붓기도 1칸 그대로**
- 짝수 크기에서 한 칸 더 가는 쪽, PC 키, 가방이 차면 남는 재료는 발밑에 떨어짐(지금과 같음)
- 고른 크기는 캐릭터마다 저장(옛 세이브는 1칸)
