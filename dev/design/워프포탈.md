## 1. 왜 하나

- 600×600 고리 지도가 넓어서 먼 지역을 오가는 시간이 길어요. 탐험한 곳을 다시 빨리 가게 해서 탐험·전투·건축을 잇는 길을 짧게 해요.
- 순간이동과 그 저장(어디에 있고 무엇이 켜졌는지)을 멀티플레이 전에 넣어 두면, 멀티 단계에서 처음부터 같이 맞출 수 있어요.

## 2. 워프포인트 (지도에 미리 놓인 것) 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 개수·자리 | **지역마다 2개씩 약 10개**(이끼 동굴·버섯숲·수정·용암·얼음), 그중 일부는 보스방 가는 길 근처. 시드마다 지역 안에서 자리를 정해요 |
| 옛 세계 | **저장된 세계에도 넣어요**. 불러올 때 지역마다 빈 자리를 찾아 놓아요 (지형은 바꾸지 않음) |
| 쓰는 조건 | **처음 가서 만지면 켜져요.** 켜진 워프포인트(또는 포탈) **앞에서만** 다른 켜진 곳으로 갈 수 있어요 |
| 고르는 화면 | 워프포인트를 누르면 **지도 창**이 열리고, 켜진 곳을 눌러 이동 |
| 비용 | **무료** |
| 켜짐 저장 | **세계 공용** (친구가 늦게 들어와도 같이 씀) |

【확정 기획】 (2026-10-18 v89 구현 때 사용자 선택):
- 등불나무 곁에 워프포인트 1개를 두고 처음부터 켜 둠 — 집에서 출발할 곳이 있어야 해서. (귀환석은 그대로라 없어도 되긴 해요)
- 1칸 크기, 지나갈 수 없는 물체. 앞에서 상호작용 버튼으로 켜기·쓰기.
- 지도: 켜진 곳은 밝은 아이콘, 밝힌 곳에 있지만 안 켜진 것은 흐린 아이콘, 안 밝힌 곳은 안 보임.
- 회수·파괴 불가, 둘레 칸은 바닥 파기·벽 쌓기 불가(막혀서 못 쓰게 되는 것을 막기).

## 3. 포탈 (만들어서 직접 놓는 것) 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 만드는 곳·재료 | **석영 작업대(3단계)**, **석영 8 · 철괴 4 · 수정결정 2 · 빛버섯 4** → 포탈 1개 |
| 연결 방식 | 놓으면 **워프 목록에 목적지 하나가 늘어요**(짝지어 잇는 방식 아님). 포탈 앞에서도 다른 켜진 곳으로 출발 |
| 개수 | **한 사람당 5개** |
| 못 놓는 곳 | 보스방 12칸 안 (바닥 파기와 같은 기준) |
| 회수 | 다른 가구처럼 **3번 쳐서 회수** (또는 상호작용 [회수]) |
| 멀티 | 놓인 포탈은 **세계 공용** — 남이 놓은 포탈도 쓸 수 있어요 |

【확정 기획】 (2026-10-18): 포탈에 이름이 없으면 지도에서 구별이 어려우니, 지도 아이콘 옆에 지역 이름 + 번호(예: 「수정 동굴 포탈 2」)를 자동으로 붙여요. 이름 바꾸기는 나중에.

## 4. 공통 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 귀환석 | **지금 그대로**: 침대가 있으면 침대로, 없으면 등불나무로. 집 근처에서 다시 쓰면 떠난 자리로 한 번 돌아가기도 그대로 |
| 이동할 때 | 목적지를 고르고 **1초 뒤 이동**, 그 사이에 맞으면 취소 |
| 몬스터 | 워프포인트·포탈 둘레 몇 칸에는 몬스터가 안 생겨요 (【확정 기획】 6칸) |
| 멀티 | 켜진 워프포인트·놓인 포탈 모두 세계 공용 |

## 5. 그림 【확정 기획】

사용자가 준 그림(2026-10-18)을 저장소 `dev/art_src/warp-portal/`에 보관했어요. 둘 다 16×16, 위에서 본 그림(top-down)을 써요.

| 쓰는 곳 | 파일 | 내용 |
|---|---|---|
| 워프포인트 | `warp/portal-purple_16px_top-down_*` | 보라 소용돌이 돌문, **6장 애니메이션**(한 장 약 0.083초, `.json`에 시간·기준점 x8 y11) |
| 포탈 | `portal/rune-stone-cyan_16px_top-down_*` | 룬 돌, **24장 — 돌이 빙글 도는 모습. 평소에도 계속 돌아요**(사용자 선택). 시간 정보 파일이 없어서 한 장 0.083초 → 한 바퀴 2초(【확정 기획】 2026-10-18) |

- 파일 종류: `outline`(테두리 있음)·`no-outline`, `unlit`(빛 안 입힌 색)·`lit`(빛 입힌 색)·`glow`/`shine`(스스로 빛나는 부분), `normal`·`lines`·`shadow`(빛 계산용 보조).
- 【확정 기획】 (2026-10-18) 게임은 새 빛(v73)이 빛을 직접 계산하므로 **테두리 있는 `unlit`을 그림으로, `glow`/`shine`을 스스로 빛나는 부분으로** 쓰는 것을 제안. 이름이 바뀐 것처럼 보이지만(워프 = `portal-purple`, 포탈 = `rune-stone`), 사용자가 준 압축 파일 이름(warp.zip / portal.zip)대로 나눴어요.
- 가방 아이콘(포탈)은 첫 장을 써요.
