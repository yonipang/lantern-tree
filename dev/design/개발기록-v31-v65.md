## 1. 큰 방향 (2026-10-09 기획안)

- **플레이 시간 10시간**을 목표로, 먼저 재고(v32) 그다음 콘텐츠를 넣음.
  - 구간 목표: 시작~구리 곡괭이 1시간 · 버섯 여왕까지 1.5시간 · 말랑대왕·수정골렘 2.5시간 · 수정 곡괭이~깊은 동굴 2.5시간 · 마무리·꾸미기 2.5시간
  - 측정 결과 데이터는 아직 저장소에 없음 (현황 문서 10장)
- **보스 체력을 올리는 대신, 보스마다 새 시스템 하나를 배우게** 한다.
- **난이도는 손(반사신경)이 아니라 준비에서** 어려워지게 한다.

## 2. 버전별로 정한 것과 이유 (v31~v40)

### v31 등불나무 성장 6단계
- 빛씨앗 0~5개에 따라 모습이 바뀜. 모습을 씨앗 개수로만 정해서 **저장 구조 변경 없음**, 옛 세이브도 바로 맞는 모습.
- 5개 완성 모습은 **금빛이 아니라 가장 짙고 풍성한 초록** + 등불·반딧불. 빛 열매는 장식만(요리 연결은 미정).
- 충돌은 줄기 3칸만, 캐노피 뒤에서는 잎 반투명(세로 모바일 때문).
- 축복은 작물에만(묘목·나무 작업장 제외). 엔딩 창은 성장 연출이 끝난 뒤 열림.

### v32 플레이 시간·클라우드 저장 개선
- 플레이 시간은 화면을 보고 있고 2분 안에 조작이 있을 때만 쌓임. 옛 세이브는 게임 속 시간으로 어림잡고 "약"을 붙임.
- **버그였던 것**: 새 기기에서 새 모험 → 로그인하면, 새 세이브가 "더 최근"이라 묻지 않고 클라우드를 덮어씀. 원인은 "저장 시각이 최근인 쪽이 이긴다" 규칙이 **서로 다른 판끼리에도** 적용된 것.
- **고친 방향**: 세이브마다 판 번호. 판이 다르면 시각과 상관없이 항상 물어봄(플레이 시간·빛씨앗·저장 시각 비교). 덮어쓰기 전 클라우드 백업 1개. 타이틀에 「클라우드에서 이어하기」.
- 클라우드 백업은 같은 문서 안에(Firestore 규칙을 안 건드리려고), 약 900KB 넘으면 백업 없이 올림.

### v33 농사 기초 / v34 농사 심화
- 농사 6단계: 심고 거두기 → 구리 낫·물 → 비료(버섯 여왕) → 흙 맞춤·별 작물(수정골렘) → 등불나무 축복(빛씨앗 3) → 지역 작물·자동화(깊은 동굴 뒤).
- **속도 상한**: 물·비료·축복을 다 겹쳐도 원래 시간의 50% 아래로는 안 내려감.
- 작물·나무 모두 4단계로 맞추고, **단계는 심은 시간으로 계산** → 저장 구조 변경 없음.
- 나무: 어린나무까지는 못 벰(실수 방지). 젊은 나무는 벨 수 있지만 적게 나오고 묘목 없음.
- 구리 낫은 들 필요 없이 가방에만 있으면 적용(v65에서 도구 주머니로 바뀜). 새 물뿌리개는 빈 채로 나옴.
- 비료 레시피는 쪽지 대신 「버섯 여왕 처치」 조건으로 나타나게 함(쪽지 시스템은 v36에서 생겨서).
- 별 작물은 다 자라는 순간 한 번 정해짐. 별 아이템은 보통 재료 대신 쓸 수 있음(보통 재료를 먼저 씀).
- 흙 이름은 게임 안 이름을 따름: 수정 모래 = 수정바닥. 씨앗은 수정 모래에도 심을 수 있게 함.

### v35 숨은 방
- 지역별 2·2·2·1·1개. 시작 지점·보스방에서 16칸 넘게, 방끼리 24칸 넘게. **손대지 않은 암반에만 파서** 옛 세이브에 생겨도 플레이어가 지은 것은 안 건드림.
- 찾기 전엔 방 안이 어두움. 지역 첫 방에는 그 지역에서만 나는 빛나는 장식.
- 가구 설계도는 넣지 않고 장식을 바로 줌(필요하면 나중에).
- 도전 퀘스트 「숨은 방 보물상자 3개 열기」는 기획에 없던 것을 찾기 동기로 추가.
- 방마다 번호(r+지역+순서)를 붙여, 나중 버전에서 이미 연 방의 쪽지를 불러올 때 줄 수 있게 함.

### v36 요리
- 요리는 자유 조합 없이 목록에서 고르기. 초기 3종만 알고 나머지는 쪽지로 해금, 모르는 요리는 ??? + 위치 힌트, 도감.
- 버프는 3칸, 같은 효과는 높은 단계 하나만. 칸이 차면 첫 번째는 알림만, 5초 안에 다시 먹으면 가장 짧게 남은 것과 교체(확인 창 대신).
- 버프 요리는 배가 불러도 먹을 수 있음.
- **물고기가 들어가는 요리는 6가지만** → 낚시를 안 해도 대부분의 버프 요리를 만들 수 있게.
- **공격력·피해 감소는 최대 15%**로 낮게(v29 보스 난이도 유지).
- **수정 분수 소원을 2단계 효과로 낮춤**: 예전엔 분수 옆에서 사실상 계속 켜 둘 수 있어서, 3단계 요리의 의미를 남기려고.
- 쪽지 출처를 단계별로 나눔: 1단계는 흔하게(몬스터·채집·낚시), 2단계는 숨은 방·도전 퀘스트, 3단계는 보스·깊은 동굴 숨은 방.
- 옛 세이브: 이미 지난 보스·방·퀘스트의 쪽지는 불러올 때 해금(이후 버전에서도 매번 맞춰 줌).

### v37 깊은 동굴 준비 (환경 압박·대비·장비 칸)
- 게이지는 용암·얼음 동굴에서만. 동굴 안 +1/초, 밖 −4/초, 보스방 반 속도.
- **교차 규칙**: 한 동굴의 재료로 다른 동굴을 대비 → 두 동굴을 오가게 함 (예: 시원 화채로 용암 → 불꽃 열매 씨앗 → 키워서 얼음 동굴 3단계 요리).
- 2단계 요리만 먹으면 처음 80초 무효과, 200초에 100 도달 → 씨앗 모으기엔 충분, 보스·장기 탐험엔 3단계 필요(의도).
- 옷 + 요리는 곱해짐. **방어력 수치는 넣지 않고 대비 효과만**(v29 난이도 유지).
- 화면 가장자리: 색뿐 아니라 모양(서리 무늬·일렁임)으로도 구분, 가운데는 비움, UI 위엔 안 그림, 보스전 중 최대 30%.
- 1·2단계 대비 요리 쪽지는 「수정 곡괭이」 퀘스트 보상 → 깊은 동굴 준비 안내 역할.
- 다른 동굴로 들어가면 게이지 0부터.

### v38 이동·패널티
- **지름길 대신 귀환석**: 집으로 갔다가, 집 근처에서 다시 쓰면 떠난 자리로 한 번 돌아감 → 깊은 동굴 왕복이 한 번에.
- 쓰러지면 재료만 스택마다 1/4을 꾸러미로(도구·무기·음식·씨앗·장식·빛씨앗은 그대로). 구리 곡괭이 전에는 안 잃음. 꾸러미가 5개를 넘으면 가장 오래된 것을 새 것에 합쳐서 재료가 사라지지 않게.

### v39 보스 3단계 (용암 거북·서리 정령)
- 원칙: **체력은 그대로, 단계마다 새 요소는 하나씩만**, 체력 막대에 66%·33% 눈금, 전환 때 1.5초 울부짖기(피해 안 받음, 날아오던 탄 사라짐), 팁은 처음 한 번.
- 2단계 시작을 체력 절반에서 66%로 당김(예전 "절반 이하" 패턴이 2단계가 됨).
- 한 번에 3단계까지 내려가도 2단계 요소(얼음 기둥)까지 함께 나옴. 얼음 기둥은 플레이어가 못 부수고 서리 정령 탄만 막음.

### v40 자동화·마무리
- 스프링클러·자동 수확기는 수정 발전기를 만든 뒤에 보임. 자동 수확기는 낫 보너스 없음·다시 심지 않음(직접 농사의 의미를 남김).
- 거대 작물은 같은 작물 2×2가 모두 맞는 흙에서 다 자라면 2×2마다 한 번만 3% 굴림.
- 등불 축제 케이크는 다섯 번째 빛씨앗 순간 해금, 탁자에 올려 장식.

### 건축 정리 (v41) — 원인과 고친 방향
- 원인(화면으로 재현): 얇은 벽은 바닥선이 칸 아래 4px 위·높이 18px이라 일반벽과 계단처럼 어긋남 / 얇은 벽이 칸 가운데라 바닥이 6px 튀어나오거나 모자람 / 문·창문이 칸마다 따로 그려져 끊김.
- 고친 방향: 지붕 삭제(옛 세이브는 재료로 돌려줌, 2개 = 1개 올림), 얇은 벽 높이·바닥선을 일반벽에 맞춤, 바닥은 벽선에서 끝남, 같은 종류가 가로로 붙으면 양문·긴 창으로 이어 그림.
- 최고 레벨에서 스킬 포인트가 하나 모자라던 문제 수정(+1 보너스).

## 4. v65 조작 개편 (2026-10-12)

### 왜 바꿨나
- v48의 "손에 든 물건의 일만 한다" 방식이 너무 불편하다는 사용자 의견(2026-10-11). 제작 UI도 불편하다는 의견이 함께 있었음.
- 처음엔 v63으로 기획했지만 다른 세션이 v63·v64(긴급 탈출 수정)를 먼저 써서 v65가 됨. 구조 변경 1단계보다 먼저, 동시에 하지 않음.

### 기획의 핵심
- 버튼 두 개: **공격**(든 무기 → 마지막 무기 → 다음으로 센 무기 → 주먹, 마지막 무기는 세이브) / **상호작용**(① 예외 → ② 일부러 든 물건이 쓸 곳이 있으면 그것 → ③ 자동 추천, 못 하면 흐리게 + 이유).
- **작은 버튼은 최대 1개** + 다음 선택지 화살표. 회수 전용·방향 전용 버튼 없앰.
- **도구 주머니**(가방 칸 안 차지) + 단축칸 맨 앞 도구 칸. 도구로는 공격 불가(도끼 포함). 곡괭이·도끼·낫·삽은 상호작용이 알아서 꺼내 듦.
- 가구는 무기·주먹으로 **세 번 쳐서 회수**(몬스터가 가까우면 몬스터를 먼저 침, 무기 안 닳음).
- 가구 방향은 **놓기 전에만**. 앉는 가구 4방향, 나머지 2방향.
- 새로 얻은 물건: 같은 칸 → 빈 단축칸 → 가방.

### 개발하며 정한 것
- 일부러 든 물건을 쓸 곳이 없을 때 앞에 다른 할 일이 있으면 그걸 추천 (예: 보스방 밖에서 소환 조각상을 들고 벽 앞 → 캐기).
- 앞에 있는 것이 「보기만」(자라는 작물·준비 안 된 동물)이거나 든 가구를 놓을 수 없으면, 회수·파기는 작은 버튼으로만.
- 물뿌리개·낚싯대·비료를 들고 못 쓸 때는 그 도구의 안내("가득 참", "물 없음", "낚싯대 고장")가 먼저.
- 자동으로 꺼낸 도구는 계속 들고 있고 더 좋은 것이 생기면 바뀜. 직접 고른 도구는 그대로.
- PC 화면 폭 1120px 이하에서는 스킬 버튼이 단축칸 위로(도구 칸 때문에 단축칸이 넓어져서).

### 기획과 다르게 된 곳 (코드가 기준)
| 항목 | 기획 | 실제 |
|---|---|---|
| 문 방향 | 가로·세로로 돌아감 | 건축 조각(문 포함)은 안 돌아감 |
| 안 돌아가는 것 | 액자·벽난로·횃불, 꽃병·둥근 탁자 | 그 밖에 어항·장화 화분·분수·거울·둥근 러그·상자·장치도. 무쇠 난로는 2방향 |
| 회수 | "회수·걷기는 상호작용에 합침" + 세 번 치기 | 둘 다 있음: 상호작용·작은 버튼의 [회수](가방으로) + 세 번 치기(바닥으로) |
| 세 번 치기 대상 | 가구·건축물 | 가구 + 직접 쌓은 나무 벽·돌벽돌 벽 |
| 낚시·물 주기 | — | 낚싯대·물뿌리개를 안 들었으면 작은 버튼에만 |

### 남은 일 · 미룬 것
- **그림 목록 전달**(아직 남음): 2방향 가구 [지금 | 옆모습], 앉는 가구 [정면 | 옆 | 뒤], 파일 이름 옆모습 `obj/<id>S.png`·뒷모습 `obj/<id>U.png`, v65 버튼 아이콘(공격·상호작용·도구 칸·화살표).
- 건축 모드(v66): "계속 들고 있기" 불편 여부도 그때 다시 논의.
- 벽 정리(코어키퍼식): 얇은 벽·창문벽·창문 틀 → 두꺼운 한 칸 벽 + 한 칸 유리벽(빛 통과), 문은 한 칸 문, 울타리 유지, 옛 세이브는 그 자리에서 변환.
  - 아직 답이 필요: 유리벽 재료(석영·수정 / 초반용 나무·돌 테두리), 반벽·기둥을 남길지, PC 오른쪽 클릭(스킬 유지 / 코어키퍼처럼 「든 물건 쓰기」).
- UI 크기: 메뉴에서 작게·보통·크게(기본 작게), CSS 토큰화 → Figma 디자인 시스템 연결. (2026-10-13에 `--ui` 0.8 고정만 들어감, 고르는 메뉴는 아직)

- 「제작」이라는 창 하나가 손 제작·작업대·용광로·요리솥·장비제작대 다섯 모양으로 바뀌고 탭 구조가 장소마다 다름(손 제작은 한 줄 글자 탭, 작업대는 아이콘 탭 + 2줄, 장비제작대는 글자 2줄).

- 회로 상태를 보는 전용 화면이 없어, 장치 정보는 [살펴보기]·[확인] → 알림으로만 보여 줌.
- 가구 사용 결과(책 읽기·거울 보기 등)는 대부분 알림으로만 보여 줌.
