# 세계관 · 메인 스토리 · NPC 기획

- 갱신: 2026-10-18
- 상태: **【확정 기획】 분위기·유적 지도 규칙 / 【검토 중】 구체적인 설정·스토리·NPC·유적 세부**
- 작업 우선순위: UI/UX 재설계의 기초 이후 상세화. 지금은 전체 UI 설계에서 필요한 시스템 범위만 참고한다.

## 확정된 방향

- **【확정 기획】 따뜻한 일상과 신비로운 모험이 공존하는 판타지.**
- 탐험 중 예상하지 못한 장소·사건·레시피·인물과의 만남을 발견하는 경험이 중요하다.
- 메인 스토리가 장기 방향을 제시하되 플레이어는 언제든 생활·제작·건축·자유 탐험에 집중할 수 있어야 한다.
- **【확정 기획】 기존 퀘스트라인은 필요하면 변경 가능하다.** 기존 빛씨앗·보스 순서가 새 스토리에 반드시 유지되어야 하는 것은 아니다.

## 미확정 세계관 제안 — '잠든 빛의 길'

> 아래는 ChatGPT가 제시한 **콘셉트 후보**이지 확정 세계관이 아니다.

한때 등불나무의 뿌리는 여러 동굴과 마을을 잇는 빛의 길이었다. 오래전 어떤 위험을 막기 위해 길이 끊어졌고, 각 지역은 고립되었다. 플레이어는 등불나무 근처에 보금자리를 만들고 생활하며, 유적·주민·탐험을 통해 그 비밀을 알아간다. 길이 다시 이어지면 주민들의 일상과 방문·교류에도 변화가 나타난다.

- 1막(안): 새 보금자리, 생활과 첫 번째 단서.
- 2막(안): 잊힌 길의 흔적, 유적·지역·주민 이야기의 교차.
- 3막(안): 길이 단절된 진실과 세계의 변화.
- 미정: 오래전 사건의 정확한 성격, 등불나무와 빛씨앗의 정체, 엔딩 조건·구현, 스토리의 분기 여부.

### 2026-10-18 Claude 제안 — 이야기 전하는 방법 【검토 중】

- 세계의 비밀은 위 「잠든 빛의 길」을 바탕으로 하고, **옛 등불지기의 일기**(예전에 이 나무를 돌보던 사람의 기록)를 따라가며 알아가는 방식. 사용자는 이 추천안을 기준으로 이야기를 이어 갔지만 따로 고르지는 않음.
- 전하는 방법(쉬운 순서): ① 기록 조각(돌판·벽화·쪽지) ② 빛씨앗을 심을 때 등불나무가 기억 한 조각을 보여 줌 ③ NPC. 추천은 ①+②로 시작, NPC는 나중에.
- 맵 쪽 제안: 워프포인트를 「끊어진 빛의 길의 정거장」으로, 보스를 「끊긴 길을 지키던 수호자」로 설명만 붙이기 → 반응이 좋으면 등불나무에서 뻗는 끊어진 뿌리 길 흔적(새 그림 필요) → NPC 때 등불지기의 옛 집터.

## 유적(던전)

### 확정 (2026-10-18, 사용자 선택)

- **【확정 기획】 지도 안 유적 구역(코어키퍼 방식).** 따로 들어가는 맵이 아니라 지금의 한 장 지도 안에 손으로 설계한 큰 유적을 둔다. 걸어서 들어간다.
- **【확정 기획】 유적 안은 지도에서 가린다.** 바깥 지도는 그대로 보이고, 유적 자리는 검게 보인다. 유적 안을 걸어 다녀도 지도에 기록되지 않는다(지도에서 밝힌 곳은 지금처럼 플레이어별).
- **【확정 기획】 유적을 깨면 그 유적 안 지도가 한 번에 모두 보인다.** 「깼다」= 마지막 방의 보스를 물리치거나 마지막 보물을 열었을 때. (유적 지도 조각을 모으는 방식은 쓰지 않음)
- **【확정 기획】 멀티에서는 깼을 때 같이 있던 사람 모두에게 그 유적 지도가 보인다.**
- **【확정 기획】 유적 안에서 쓰러져도 기절 꾸러미 화살표(주황)는 보인다.**

### 남은 제안 【검토 중】 (Claude 추천, 사용자 확인 전)

- 유적 벽은 곡괭이로 못 캠(벽을 뚫고 지름길로 가면 유적 의미가 없어서). 유적 안 바닥 파기·건축 허용 여부도 정해야 함
- 처음에는 **이끼 동굴에 시험 유적 1개** → 재미있으면 지역마다 하나씩
- 유적 = 끊어진 빛의 길의 옛 역참, 안에 등불지기의 일기 조각
- 막힌 문은 지금 있는 회로(스위치·전선)로 열기, 어두운 유적을 횃불로 밝혀 가는 재미(v88 몬스터 빛 피하기와 연결)
- 워프포인트는 유적 안에 두지 않고 입구 앞에, 포탈은 유적 안에 못 놓음
- 퀘스트 화살표는 지금 규칙(지도에서 밝힌 곳만) 그대로라 깨기 전 유적 안 목표는 가리키지 않음
- 마지막 방 보상(보스·빛씨앗·레시피 등). 빛씨앗을 유적으로 옮기면 이야기 퀘스트 순서·옛 세이브 검토 필요
- 유적은 새로 만든 세계에만 생김 → 옛 세계에 끼워 넣을지 정해야 함
- 개발 순서: v89 워프·v90 건축 다음, 멀티 전인지 후인지 사용자가 정함

## 미확정 NPC 역할안

| 역할 후보 | 핵심 경험 | 유의점 |
|---|---|---|
| 등불지기 | 일상·세계의 기억·스토리 단서 | 단순 퀘스트 전달원으로만 사용하지 않는다 |
| 탐험가 | 예상 밖의 장소·유적·모험의 실마리 | 정해진 순서의 강제 방문을 피한다 |
| 장인 | 잊힌 제작법·가구·공방의 이야기 | 건축을 NPC 해금의 의무 노동으로 만들지 않는다 |

NPC는 자신의 생활·목표·관계를 가진 존재여야 한다. 일부는 메인 줄거리와 무관한 독립적인 이야기를 가져야 세계가 넓게 느껴진다. 이름·인원·직업·관계·친밀도·거주·상점·자유 이동 등은 **모두 미확정**이다.

## UI/UX 선행 설계에 필요한 최소 요구사항 (검토 중)

1. NPC 또는 세계 오브젝트와 상호작용해 짧은 대화·단서를 확인할 수 있는 UI의 확장성.
2. 메인 스토리/시스템 안내/선택 목표를 구별할 수 있는 정보 구조.
3. 발견한 기록·장소·인물을 다시 살펴볼 수 있는 진입점의 가능성.

세 항목은 세부 UI 또는 게임 시스템의 **확정 기능 목록이 아니다**. 당장 인물 도감·호감도·선물·거주 시스템까지 구현하자는 의미가 아니다.

## 실제 게임과의 관계

- 【구현】 이끼 동굴·버섯숲·수정·용암·얼음 지역, 보스, 숨은 방, 빛씨앗과 등불나무 성장 요소가 현재 코드에 있다.
- 【미구현】 대화 가능한 주민 NPC 및 관계 시스템은 현황 문서에서 미구현으로 확인되어 있다.
- 빛씨앗 획득·보스 드롭·퀘스트 보상·엔딩·일부 해금이 서로 연결되어 있으므로, 메인 진행 구조를 바꾸면 `dev/src/js/data/quests.js`, `dev/src/js/sim/quests.js`, `dev/src/js/sim/tree.js`, 보스/저장 코드 등의 의존성을 Claude가 검토해야 한다.

## 멀티플레이의 NPC·퀘스트·스토리 설계 제약

**【확정 기획 · 2026-10-14】 싱글플레이·멀티플레이 모두 플레이 중 NPC 대화창을 열어도 세계 시간과 몬스터 행동은 계속된다.** 따라서 NPC 대화는 안전한 종료·재개 가능성과 피격 인지, 모바일 화면 가림을 고려한다. 대화 중 피격 시 자동 종료·대사 일시 보류·무적 부여 등 세부 정책은 아직 【검토 중】이며 NPC 자체도 현재 【미구현】이다.

**【확정된 멀티플레이 구조】** 한 세계는 방장 기기가 계산·저장하며, 플레이어 캐릭터는 각자 기기에 저장된다. `save/state.js` 기준 현재의 퀘스트 진행과 보상 수령 기록은 **세계 공통**, 레시피 학습과 장비·인벤토리는 **캐릭터 소유**, 탐험으로 밝힌 지도와 부활·귀환 위치는 **세계 안 플레이어별**이다.

이 구조가 곧 미래 NPC·스토리 규칙을 확정하는 것은 아니다. 신규 시스템 설계 시 아래를 각각 별도로 결정한다.

| 항목 | 현재 확인/검토 기준 | 결정 상태 |
|---|---|---|
| 메인 이야기의 진행 | 현재 이야기 퀘스트와 받은 보상 기록은 세계 공통 | 【구현】 현행 규칙; 재설계 여부 미정 |
| 퀘스트 수락·진행 | 세계 공동 진행인지, 세계 안 개인별 진행인지, 퀘스트마다 혼합할지 | 【검토 중】 |
| 완료 보상 | 세계 공통 1회 수령인지, 기여자별 또는 참가자별 수령인지 | 【검토 중】 |
| NPC 대화·선택지 기록 | 모두 공유할지, 개별 인물 경험으로 기록할지 | 【검토 중】 |
| NPC 친밀도·관계 | 세계 전체 관계인지, 캐릭터별 또는 세계 안 플레이어별인지; 기능 자체를 넣을지도 미정 | 【검토 중】 |
| 레시피 발견 | 현재 학습 기록은 캐릭터 소유, 쪽지를 사용한 사람에게만 학습됨 | 【구현】 현행 규칙; 협동 공유 규칙은 미정 |
| 이야기 사건 알림 | 본인만/동료도/세계 전체 수신 중 무엇이 적절한지 | 【검토 중】 |
| 대화 도중 세계 진행 | 싱글·멀티 모두 NPC 대화 중 세계와 몬스터가 계속 행동함. 안전성·피격 안내·취소/재개 필요 | 【확정 기획】 세계 계속 진행 / 【검토 중】 대화 중 상세 조작 |

**중요:** 공동 퀘스트 진행과 개인별 보상은 독립적으로 판단한다. 지금의 `qclaim`은 세계 소유여서 먼저 보상을 받으면 다른 참가자의 독립 수령이 불가능하다. 개인별 수령을 원한다면 보상 식별자·저장 구조·이전 세이브 호환성까지 개발 검토가 필요하다.

이야기 퀘스트의 기존 완료 조건은 불러올 때 재계산되므로 순서·조건 변경과 식별자 변경 시 이미 받은 보상·빛씨앗·보스 진행·엔딩·해금에 영향을 줄 수 있다. **사용자 승인 전 새 저장 규칙이나 보상 분배를 확정하지 않는다.**
