# 건축 모드

- 마지막 갱신: 2026-10-18
- 상태: **【확정 기획】** (2026-10-18 사용자 선택: 연속 놓기·건축 목록·옮기기·뜯기 모두). 표에 【검토 중】이라고 적은 칸만 아직 Claude 제안이에요.
- 구현: **v90** (v89 워프·포탈 다음, 멀티플레이 전). 크면 v90·v91 둘로 나눠요.
- 관련: [기획-결정사항.md](./기획-결정사항.md), [바닥파기.md](./바닥파기.md)(바닥 바꾸기·메우기), 지금 코드 상태는 [등불나무-최신게임현황.md](./등불나무-최신게임현황.md) 4-8(건축·배치)·4-28(바닥 파기)

## 1. 왜 하나

- 지금은 단축칸에 들고 한 칸씩 놓고, 회수는 3번 쳐야 해요. 집·길·방을 지을 때 손이 많이 가요(v65 기획 때 「계속 들고 있기」 불편으로 남겨 둔 것).
- 건축은 기획 가이드의 세 기둥(탐험·전투·건축) 중 하나라, 짓고 고치는 손맛을 따로 만들어요.

## 2. 켜고 끄기 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 켜는 곳 | **가방 창 안의 「건축」 버튼** |
| 지금 방식 | 단축칸에 들고 상호작용으로 놓기는 **그대로 둬요** (횃불 하나 놓기 등) |
| 모드 안에서 | 공격·채집은 안 돼요. **세계는 계속 진행**, 맞으면 창을 연 채 맞을 때와 같이 빨간 번쩍·경고만 |

【검토 중】 PC 단축키 Z (Claude 제안, 아직 답 없음).

**함께 정한 것 — 가방 창 설명 글 빼기 【확정 기획】**: 가방 창에 있는 설명 글은 **모두 빼요**(자리를 너무 차지함). 사용법은 나중에 설정 메뉴의 「사용법 모음」에 넣어요(따로 기획). 건축 모드와 같은 버전에 해요.

## 3. 건축 목록 (B) 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 자리 | 화면 아래, 분류 탭(벽·바닥·가구·조명·제작대·회로·자연) + 칸 |
| 개수 | 칸에 **가방 + 가까운 상자(16칸 안)** 에 있는 개수를 합쳐 보여 줘요. 놓으면 가방 먼저, 그다음 가까운 상자에서 써요 |
| 완성품이 없을 때 | **「만들어서 놓기」**: 지금 만들 수 있는 레시피(해금됨 + 재료 있음)면 제작 화면을 거치지 않고 재료로 바로 놓아요 |

【검토 중】 Claude 제안: 「만들어서 놓기」도 그 레시피를 만드는 **제작대 단계까지 올렸어야** 쓸 수 있어요(제작대 단계의 의미를 지키기 위해). 단, 제작대 곁에 서 있을 필요는 없어요. 재료가 모자라면 칸이 흐리게.

## 4. 놓기·연속 놓기 (A) 【확정 기획】

| 항목 | 정한 것 |
|---|---|
| 거리 | 캐릭터 둘레 **8칸** 안 |
| 연속 놓기 | **벽·바닥·울타리**는 끈 칸을 따라 여러 칸을 한 번에 |
| **바닥 여러 개** | 바닥은 한 번에 여러 칸 놓을 수 있어요 (사용자 요청) |
| 미리보기 | 놓을 칸이 비쳐 보여요. 초록 = 됨, 빨강 = 안 됨 |
| 폰 조작 | 건축 모드일 때 조이스틱은 **왼쪽 아래 모서리**에만, 나머지 화면 누르기·끌기는 건축 |

【검토 중】 「바닥 여러 개」를 어떻게 놓을지: Claude 제안은 **바닥은 끌면 네모(시작 칸 ~ 끝 칸 사각형)로 채우기**, 벽·울타리는 끈 길을 따라 한 줄. 한 번에 최대 칸 수는 구현 때 정함(예: 64칸).

## 5. 지형 편집 — 벽·바닥 교체 【확정 기획】

- 건축 모드에서 **벽과 바닥을 다른 것으로 바꿀 수 있어요** (사용자 요청 「가능하면」).

【검토 중】 Claude 제안 규칙:
- **바닥 교체**: 바닥 위에 다른 바닥을 놓으면 바뀌고 원래 바닥은 돌려받아요 — v87 삽 「바꾸기」와 같은 규칙. 못 파는 곳(보스방 12칸·등불나무 둘레 9.5칸)은 그대로 막아요.
- **벽 교체**: 직접 쌓은 벽 위에 다른 벽을 놓으면 바뀌고 원래 벽을 돌려받아요. **자연 벽(흙·돌·화강암·현무암·얼음·광맥)** 은 **지금 가진 곡괭이로 캘 수 있는 벽만** 바꿀 수 있고, 캤을 때와 같은 것(광맥은 광석)을 받아요. 보스방 바위 고리·암반은 안 돼요.
- 구덩이 파기는 지금처럼 삽으로(건축 모드에 넣을지는 나중에).

## 6. 옮기기 (C) 【확정 기획】

- 놓인 가구를 누르면 잡히고, 다른 칸을 누르면 옮겨져요. 잡은 채 **돌리기** 버튼.
- **물건이 든 상자, 굽는 중인 용광로·요리솥도** 내용과 진행을 그대로 둔 채 옮겨요.
- 여러 칸 가구는 새 자리 모든 칸이 비어야 해요.

## 7. 뜯기 (D) 【확정 기획】

- **한 번 누르면** 가방으로(가득이면 바닥에 떨어짐). **끌면 여러 칸**을 한꺼번에.
- **직접 놓은 것만** 뜯어요. 물건이 든 상자는 지금처럼 안 돼요.
- **마지막 한 번 되돌리기** 버튼.

## 8. 멀티 【확정 기획】

- 「친구도 모든 행동 가능」 규칙대로, 남이 놓은 것도 옮기고 뜯을 수 있어요. 놓기·옮기기·뜯기·교체는 모두 세계 변화로 모두에게 보내요.
- 【검토 중】 되돌리기는 내가 한 마지막 일만.

## 9. 순서 【확정 기획】

v88(몬스터 빛 피하기·구리 작업대 흙) → **v89 워프·포탈** → **v90 건축 모드**(+ 가방 설명 글 빼기) → 멀티플레이 12~15단계.

## 10. 그림·화면

- 새 그림: 「건축」 버튼 아이콘, 모드 안 「옮기기·뜯기·되돌리기·돌리기」 아이콘 — 그림이 오기 전엔 글자 버튼.
- 화면 배치(건축 목록 높이, 모드 바꾸기 버튼 자리)는 구현 전에 배치 미리보기로 확인받아요.
