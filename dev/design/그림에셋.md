## 받은 파일

- 2026-10-21 사용자가 올린 zip(`source.zip`, 그림 약 100장 + rar 4개). 사용 조건: **사용자가 「모두 사용해도 된다고 적혀 있었다」고 확인**. Fantasyville(동굴·대장간·식료품점·마을·실내)은 예전에 산 팩(v54).
- 원본 시트는 저장소에 올리지 않고, **쓰는 조각만 잘라 `dev/art/`에 넣는다**(v54와 같은 방식). 그래서 구현할 때 zip을 다시 받아야 한다. 잘라 낼 자리는 아래 표에 적었다(x, y, 너비×높이, px).
- Claude는 그림을 새로 그리지 않고 **자르기·크기 맞추기·테두리 지우기 같은 처리만** 한다(사용자 요청). 아래 작물 아이콘의 흰 테두리 지우기는 사용자가 2026-10-21에 요청함.

## 고르는 기준 【확정 기획 · 2026-10-21】

1. **게임에 넣어도 깨지거나 흐려 보이지 않아야 한다.** 한 칸 16px, 그림 픽셀 = 게임 픽셀(1:1)인 것만. 32px 기준 그림을 반으로 줄이면 깨지므로 안 씀.
2. **게임의 분위기·색·톤과 어울려야 한다.** 진한 테두리, 맑은 색.
3. **스타일이 너무 다른 그림은 쓰지 않는다.** 청록 나무·청록 침엽수·큰 숲 나무처럼 부드럽게 칠한 큰 나무는 지양(나중에 사용자 손그림으로 바꾸면 다시 볼 수 있음). GL·GD 타일의 이끼 바위·연꽃 같은 작은 소품은 **일단 유지**.
4. **현대 느낌 팩도 톤이 어울리면 쓴다.** 냉장고·변기·TV처럼 현대 물건인 게 바로 보이는 것은 뺀다.
5. **가구는 너무 큰 것은 빼고, 커도 말이 되는 것(침대·두 칸 옷장·긴 탁자)은 넣는다.** 크기가 애매한 것(키 큰 옷장, 벽난로)은 뺀다.

## 남은 것 【검토 중】

- 위 표의 → (어느 게임 그림을 바꿀지)는 Claude 추천. 구현 전에 확인.
- 새 아이템의 이름·레시피·작업대 단계·칸 크기. 침대처럼 **지금보다 커지는 가구**(침대 1×1.5칸 → 2×3칸)는 놓인 옛 가구가 옆 칸을 덮지 않게 처리 방법을 정해야 함.
