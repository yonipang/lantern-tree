## 공통 설계 기준
기존 게임의 탐험·전투·건축 연결성과 모바일 조작 부담을 개선한다. 싱글·멀티 모두 메뉴를 열어도 세계가 계속 진행된다는 확정 기획을 유지한다(현재 구현 여부와 구분). 기존 세계·캐릭터 저장 데이터를 보존한다. 기능 변경 시 멀티플레이 상태 소유권과 피드백 대상을 확인한다.

## BF-01 중복 상호작용에 바닥 아이템 줍기
**【확정 기획】** 상호작용 대상이 겹치는 상황의 후보 목록에 떨어진 아이템 줍기를 포함한다.
- 후보 탐색 시 동일 위치의 아이템과 가구·기타 상호작용을 함께 인식한다. 선택하면 기존 획득 처리(거리·용량·수량·소유권)를 따른다.
- 【검토 중】 동일 종류 여러 개를 한 항목으로 묶는 방식; 자동 줍기와의 중복 처리.
- 예외: 인벤토리가 가득 찼으면 아이템을 소실하지 않는다. 이미 획득된 아이템은 후보에서 제거한다.
- 검증: 아이템+가구, 아이템+다른 대상, 다종 아이템, 가방 가득 참, 멀티 동시 줍기.

## BF-02 모바일 복귀 후 오디오 복원
**【확정 기획】** 모바일 화면 잠금/해제 및 앱 전환 복귀 뒤 BGM·효과음이 정상 작동해야 한다.
- 사용자 음소거/볼륨 설정을 유지한다. 중복 BGM 재생 금지.
- 브라우저 오디오 재개 제한 시 다음 사용자 입력에서 재개를 시도한다.
- 확인: 오디오 관리 방식, AudioContext 상태, visibilitychange/pageshow 및 재개 시점.
- 검증: iOS Safari·PWA에서 반복 잠금/복귀, 음소거 상태, 효과음/BGM.

## BF-03 자연 체력 회복
**【확정 기획】** 마지막 피격 후 5초부터 자연 회복한다. 추가 피격 시 5초 대기를 다시 시작한다.
- **【테스트 수치】** 초당 최대 HP 약 1%. 사용자 최종 밸런스 승인 전 확정 수치 아님.
- 최대 HP 초과 금지, 프레임레이트에 독립적인 시간 누적, 소수 회복량 누적.
- 메뉴가 열려도 세계가 진행되는 확정 기획과 일치시킨다. 다만 실제 현재 코드의 일시정지 처리와 분리해서 검토한다.
- 【검토 중】 백그라운드 회복 여부, 버프·음식과의 중첩, 사망/부활 시 초기화.
- 검증: 연속 피격, 저FPS, 메뉴 중, 저장·로드, 전투 밸런스/음식 가치.

## BF-04 지역 내부 랜덤 월드 생성
**【확정 기획】** 기존 5개 지역과 진행·해금 구조는 유지하며, 새 세계 생성 시 각 지역의 내부 지형과 콘텐츠 배치를 규칙 기반으로 랜덤화한다. 저장한 세계를 열 때 다시 생성하지 않는다.
- 현재 현황 문서상 별도 던전 맵이 아닌 연결된 세계의 보스방 5곳과 숨은 방이 존재한다. 새로운 던전 시스템은 이 요청으로 확정된 것이 아니다.
- 생성 흐름 【권장안】: 지역 골격·진행 조건 → 시작점과 필수 연결로 → 지형 → 보스방·숨은 방 후보 → 자원·오브젝트 → 유효성 검사.
- 보스: 해당 진행 지역 안에 배치, 접근 경로와 전투 공간 확보. 숨은 방: 탐험으로 발견할 수 있는 지형에 배치하고 필수 통로 차단 금지.
- 필수 자원·퀘스트 목표·보스·제단·지역 간 연결의 접근성을 검증한다. 고정 좌표를 참조하는 시스템은 생성 결과 좌표로 연결한다.
- 【권장안】 시드·생성 규칙 버전 보존, 기존 월드 데이터 유지, 수백 개 시드 자동 검증. 싱글·멀티 공통 월드 상태를 고려한다.
- 【검토 중】 정확한 지역 크기, 보스 최소 거리, 숨은 방 수·확률, 지형 변화 범위, 세이브 마이그레이션. 코드 조사와 별도 상세 승인 후 구현.
- 검증: 다수 시드에서 진행 불가·고립·필수 보상 누락 없음, 저장/재접속 동일 지형, 구 세이브 보존.

## BF-05 반벽·기둥 제거와 구 데이터 변환
**【확정 기획】** 반벽과 기둥을 신규 제작·배치 목록에서 제거한다. 기존에 사용한 기록이 있는 경우 해당 재료의 일반 벽으로 변환한다.
- 설치물은 기존 좌표를 유지하며 재료에 맞는 벽으로 변환한다.
- 【권장안】 인벤토리·단축칸·창고 보유분도 같은 재료 일반 벽으로 변환. 정확한 수량 환산은 코드 확인.
- 제작 레시피·드롭·해금·충돌·벽 연결 렌더링·저장 ID 전체 조사.
- 예외: 겹친 건축물, 재료 매핑 불가, 데이터 손상 시 조용히 삭제하지 않고 보고.
- 검증: 구 세이브 백업 후 변환, 반복 로드 시 중복 변환 없음, 건축물 위치·소유 정보 보존.

## BF-06 가방 닫은 뒤 단축칸 선택 유지
**【확정 기획】** 가방에서 단축칸 아이템을 클릭한 뒤 닫아도 해당 단축칸 선택을 유지한다.
- 【권장안】 선택한 슬롯 번호를 유지하며, 명시적으로 다른 슬롯을 선택하면 갱신. 닫기 자체가 아이템 사용을 유발하지 않는다.
- 【확인 필요】 현재 선택 상태가 슬롯 번호인지 아이템 ID인지.
- 검증: 열기/닫기, 슬롯 변경, 아이템 이동·소모, 빈 슬롯, 모바일 터치.

## BF-07 수정 결정 철 곡괭이 채굴
**【확정 기획】** 수정 결정은 철 곡괭이로 채굴 가능하도록 변경한다. 상위 등급도 허용하고 하위 등급은 기존 제한 유지.
- 채굴량·드롭·속도·내구도·다른 광맥 제한은 별도 요청 없이 변경하지 않는다.
- 【확인 필요】 실제 수정 결정 ID, 도구 등급, 수정 관련 진행 관문과 퀘스트 영향.
- 검증: 하위/철/상위 도구, 진행 단계 우회 여부.

## BF-08 잃어버린 꾸러미 위치 안내
**【확정 기획】** 기존 퀘스트 방향 화살표와 유사하게 잃어버린 꾸러미 방향을 표시한다. 여러 꾸러미가 있으면 **가장 가까운 꾸러미**를 안내한다.
- 위치·회수 상태에 따라 실시간 갱신하고 회수 시 안내 제거, 저장/로드 후에도 유지.
- 【검토 중】 '가까움'의 거리 계산(실제 경로 거리 권장, 계산 비용 확인), 퀘스트 화살표 동시 표시, 타 지역 꾸러미 처리.
- 멀티에서는 꾸러미 소유자에게만 표시하는 방식을 권장하나 실제 소유 범위는 확인 후 확정.
- 검증: 여러 꾸러미, 이동에 따른 목표 변경, 회수, 재접속, 다른 지역, 멀티.

## BF-09 건축 시 플레이어 자동 밀어내기
**【확정 기획】** 가구·문·벽 배치 위치에 플레이어가 겹치면 상하좌우 **4칸만** 검사해 이동 가능한 인접 칸으로 옮기고 배치한다.
- 설치 전에 유효 이동 칸을 확인하고 이동과 설치를 원자적으로 처리한다. 네 칸 모두 불가능하면 설치 취소·재료 미소모.
- 장애물·지형·몬스터·다른 플레이어와의 충돌, 다칸 가구의 점유 범위를 검사한다.
- 【검토 중】 여러 후보 중 방향 우선순위, 다른 플레이어와 겹치는 배치의 허용 여부.
- 검증: 각 방향, 네 방향 막힘, 다칸 가구, 재료 부족, 저장/로드, 멀티 충돌.
