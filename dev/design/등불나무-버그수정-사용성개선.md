## 공통 설계 기준
기존 게임의 탐험·전투·건축 연결성과 모바일 조작 부담을 개선한다. 싱글·멀티 모두 메뉴를 열어도 세계가 계속 진행된다는 확정 기획을 유지한다(현재 구현 여부와 구분). 기존 세계·캐릭터 저장 데이터를 보존한다. 기능 변경 시 멀티플레이 상태 소유권과 피드백 대상을 확인한다.

## BF-01 중복 상호작용에 바닥 아이템 줍기
**【확정 기획】** 여기서 대상은 일반 몬스터 드롭이 아니라 기절 시 남는 **잃어버린 꾸러미(lostBag)**다. 꾸러미가 다른 상호작용 대상과 겹치거나 발밑·옆에 있어도 되찾기 후보에 포함한다.
- 후보 탐색 시 동일 위치의 아이템과 가구·기타 상호작용을 함께 인식한다. 선택하면 기존 획득 처리(거리·용량·수량·소유권)를 따른다.
- 【검토 중·추천】 바라보는 칸의 꾸러미는 기존 큰 버튼을 우선하고, 발밑·옆의 꾸러미는 작은 후보 버튼에 표시. 여러 꾸러미 후보의 선택 기준은 추가 결정 필요. 일반 드롭 자동 줍기와는 별개.
- 예외: 인벤토리가 가득 찼으면 아이템을 소실하지 않는다. 이미 획득된 아이템은 후보에서 제거한다.
- 검증: 아이템+가구, 아이템+다른 대상, 다종 아이템, 가방 가득 참, 멀티 동시 줍기.

## BF-02 모바일 복귀 후 오디오 복원
**【확정 기획】** 모바일 화면 잠금/해제 및 앱 전환 복귀 뒤 현재 구현된 **효과음이 정상 작동해야 한다.** 현재 BGM은 【미구현】이며 신규 BGM 도입은 이번 범위 밖이다.
- 사용자 음소거/볼륨 설정을 유지한다. 중복 BGM 재생 금지.
- 브라우저 오디오 재개 제한 시 다음 사용자 입력에서 재개를 시도한다.
- 확인: 오디오 관리 방식, AudioContext 상태, visibilitychange/pageshow 및 재개 시점.
- 검증: iOS Safari·PWA에서 반복 잠금/복귀, 음소거 상태, 효과음/BGM.

## BF-03 자연 체력 회복
**【확정 기획】** 마지막 피격 후 5초부터 자연 회복한다. 추가 피격 시 5초 대기를 다시 시작한다.
- **【확정 기획】** 기존 회복 속도 **2.5초마다 HP +1(평균 초당 0.4 HP)** 유지. 최대 HP 비율 기반 회복(1%/초) 제안은 철회한다.
- **【확정 기획】** 기존 회복 조건인 배고픔 55 이상, 더위 2단계 이상 시 중단을 유지한다. 마지막 피격 후 5초 대기 규칙을 기존 자연 회복 처리에 추가한다.
- **【검토 중】** 앉기·회복 스킬·음식 회복·회복 버프는 기존 동작을 우선 보존하며, 피격 후 5초 대기가 자연 회복에만 적용되는지 후속 검토한다. 회복약·제약대는 별도 신규 콘텐츠 제안으로 이번 BF 구현 범위에 포함하지 않는다.
- 최대 HP 초과 금지, 프레임레이트에 독립적인 시간 누적, 소수 회복량 누적.
- 메뉴가 열려도 세계가 진행되는 확정 기획과 일치시킨다. 다만 실제 현재 코드의 일시정지 처리와 분리해서 검토한다.
- 【검토 중】 백그라운드 회복 여부, 버프·음식과의 중첩, 사망/부활 시 초기화.
- 검증: 연속 피격, 저FPS, 메뉴 중, 저장·로드, 전투 밸런스/음식 가치.

## BF-04 지역 내부 랜덤 월드 생성
**【확정 기획】** 기존 5개 지역과 진행·해금 구조는 유지하며, 새 세계 생성 시 각 지역의 내부 지형과 콘텐츠 배치를 규칙 기반으로 랜덤화한다. 저장한 세계를 열 때 다시 생성하지 않는다.
- 현재 현황 문서상 별도 던전 맵이 아닌 연결된 세계의 보스방 5곳과 숨은 방이 존재한다. 새로운 던전 시스템은 이 요청으로 확정된 것이 아니다.
- **【확정 기획】 2단계 랜덤화**: 기존 지역 방향·크기·진행 순서와 깊은 지역 진입 장벽을 유지하면서 내부 지형·자원 밀도를 다양화하고, **보스방 5곳·제단 위치 및 보스방으로 이어지는 굴 끝점을 해당 지역 안에서 시드별로 변경**한다. 지역 방향 자체를 바꾸는 3단계는 제외한다.
- **【구현 — Claude 기술 검토】** 현재 동굴·광맥·웅덩이·숨은 방 8곳 등은 이미 시드에 따라 변하며, 보스·제단 위치는 고정이다. 기존 기능을 중복 구현하지 않고 랜덤화 범위를 확장한다.
- 생성 흐름 【권장안】: 기존 지역 골격 → 지역 내 보스·제단 위치 선정 → 필수 경로 확보 → 내부 지형 변화 → 숨은 방·자원·물체 → 접근성·진행 검증.
- 보스: 해당 진행 지역 안에 배치, 접근 경로와 전투 공간 확보. 숨은 방: 탐험으로 발견할 수 있는 지형에 배치하고 필수 통로 차단 금지.
- 필수 자원·퀘스트 목표·보스·제단·지역 간 연결의 접근성을 검증한다. 고정 좌표를 참조하는 시스템은 생성 결과 좌표로 연결한다.
- 【권장안】 시드·생성 규칙 버전 보존, 기존 월드 데이터 유지, 수백 개 시드 자동 검증. 싱글·멀티 공통 월드 상태를 고려한다.
- **【권장안·미승인】** 숨은 방 수는 기존 8개를 우선 유지하고 위치만 변화; mapV=3을 새 월드에만 적용하고 기존 mapV=1·2는 기존 생성 규칙 유지. 자연 바위 판정·옛 세이브 보정이 시드로 지형을 재계산하므로 반드시 버전 분기.
- 【검토 중】 시작점·보스방 최소 거리, 보스 간 거리, 각도·거리 변동 폭, 자원 최소 개수, 생성 실패 재시도 상한·최종 복구 정책. 세부 수치 승인 전 BF-04 구현 보류.
- 검증 기준 【권장】 평상시 20시드 + 별도 300시드 이상; 필수 경로·자원·숨은 방, 구 세이브 불변, 모바일 생성 시간 측정.
- 검증: 다수 시드에서 진행 불가·고립·필수 보상 누락 없음, 저장/재접속 동일 지형, 구 세이브 보존.

## BF-05 반벽·기둥·얇은 벽 제거 및 재료 환급
**【확정 기획】** 반벽·기둥에 더해 **얇은 벽**도 신규 제작·설치 대상에서 삭제한다. 기존 제작·설치·보관분은 같은 일반 벽으로 변환하는 종전 방식을 폐기하고 **제작에 사용한 원재료를 환급**한다.
- 환급 대상: 기존 세계에 설치한 대상, 가방·단축칸·상자·잃어버린 꾸러미 안에 남은 대상. 환급은 저장 데이터에서 제거/정리하기 전에 처리하고 재로드해도 중복 환급되지 않아야 한다.
- **【구현된 제작법 — Claude 검토】** 얇은 벽: 나무 2→2개 또는 돌 4→2개이므로 조각당 나무 1 또는 돌 2. 반벽·기둥: 나무 1→2개 또는 돌 2→2개이므로 조각당 나무 0.5 또는 돌 1. 같은 재료별 환급량을 합산한 뒤 올림하는 방식을 【권장안】으로 제시한다. 환급 수량 산식의 최종 승인은 별도.
- **중요한 플레이 영향:** 설치된 얇은 벽을 제거하면 기존 집의 벽이 사라져 실내가 뚫리고 문이 고립될 수 있다. 이는 사용자 선택의 결과이며 자동으로 일반 벽을 대체 설치하지 않는다. 로드 시 한 번 안내하는 방식은 【권장안】.
- **【검토 중】** 창문벽·창문 틀을 함께 삭제할지(현재 유리벽 대체재 미구현). 승인 전에는 제거 범위에 포함하지 않는다.
- **【검토 중·권장】** 환급 재료가 가방에 다 들어가지 않으면 발밑 드롭 대신 저장되는 **환급 전용 상자** 등에 보관. 현재 일반 바닥 드롭은 저장되지 않아 종료 시 소실 위험이 있다. 상자 생성 위치·중복 방지·멀티 귀속은 승인 필요.
- 예외: 원재료 매핑 불가, 기존 월드의 다른 물체와 중첩, 저장 데이터 손상은 소리 없이 삭제하지 말고 보존·보고한다. 오래된 세이브의 가방·세계·상자·꾸러미 변환 모두 필요하다.
- 검증: 구 세이브 샘플, 재료별 환급 총량, 여러 번 로드해도 중복 환급 없음, 가방 가득 참, 삭제된 건축물의 충돌/렌더링 오류 없음, 멀티의 세계·캐릭터 저장 구분.

## BF-06 가방 닫은 뒤 단축칸 선택 유지
**【확정 기획】** 가방에서 단축칸 아이템을 클릭한 뒤 닫아도 해당 단축칸 선택을 유지한다.
- 【권장안】 선택한 슬롯 번호를 유지하며, 명시적으로 다른 슬롯을 선택하면 갱신. 닫기 자체가 아이템 사용을 유발하지 않는다.
- **【구현 — Claude 기술 검토】** 현재 손에 든 칸은 슬롯 번호 `G.sel`(0~8, 도구 -1)이고 가방 선택은 `UIS.invSel`로 분리되어 있다. `pickHot`은 같은 칸 재선택 시 음식 섭취 등이 발생할 수 있으므로 **사용 동작 없이 선택만 갱신하는 명령**을 사용한다.
- 【권장안】 가방의 비단축칸을 누를 때는 손에 든 칸을 바꾸지 않는다.
- 검증: 열기/닫기, 슬롯 변경, 아이템 이동·소모, 빈 슬롯, 모바일 터치.

## BF-07 수정 결정 철 곡괭이 채굴
**【확정 기획】** 수정 결정은 철 곡괭이로 채굴 가능하도록 변경한다. 상위 등급도 허용하고 하위 등급은 기존 제한 유지.
- 채굴량·드롭·속도·내구도·다른 광맥 제한은 별도 요청 없이 변경하지 않는다.
- **【구현 — Claude 기술 검토】** `OBJ.cluster`의 현재 필요 등급은 1(구리)이며, 변경 목표는 2(철). 철 곡괭이는 석영 없이 제작 가능하여 주요 진행이 막히지 않지만 석영·수정 콩 씨앗 등의 획득 시점은 뒤로 이동한다.
- 검증: 하위/철/상위 도구, 진행 단계 우회 여부.

## BF-08 잃어버린 꾸러미 위치 안내
**【확정 기획】** 기존 퀘스트 방향 화살표와 유사하게 잃어버린 꾸러미 방향을 표시한다. 여러 꾸러미가 있으면 **가장 가까운 꾸러미**를 안내한다.
- 위치·회수 상태에 따라 실시간 갱신하고 회수 시 안내 제거, 저장/로드 후에도 유지.
- 【검토 중·추천】 **직선거리**로 가장 가까운 꾸러미를 선정한다. 최대 5개이고 채굴로 경로가 바뀌므로 실제 최단 경로 계산의 비용 대비 이점이 작다. 기존 퀘스트 화살표와 구별되는 색·아이콘을 사용하고 다른 지역의 꾸러미도 표시하는 방향을 권장한다.
- 멀티에서는 꾸러미 소유자에게만 표시하는 방식을 권장하나 실제 소유 범위는 확인 후 확정.
- 검증: 여러 꾸러미, 이동에 따른 목표 변경, 회수, 재접속, 다른 지역, 멀티.

## BF-09 건축 시 플레이어 자동 밀어내기
**【확정 기획】** 가구·문·벽 배치 위치에 플레이어가 겹치면 상하좌우 **4칸만** 검사해 이동 가능한 인접 칸으로 옮기고 배치한다.
- 설치 전에 유효 이동 칸을 확인하고 이동과 설치를 원자적으로 처리한다. 네 칸 모두 불가능하면 설치 취소·재료 미소모.
- 장애물·지형·몬스터·다른 플레이어와의 충돌, 다칸 가구의 점유 범위를 검사한다.
- 【검토 중·추천】 **플레이어가 서 있는 칸** 기준 네 방향을 검사하고, 바라보는 반대쪽 → 좌우 → 앞 순서로 후보를 평가한다. 다칸 가구 전체 점유 영역과 겹치지 않아야 한다. 다른 플레이어·몬스터가 겹치는 배치는 밀지 않고 거절한다.
- 검증: 각 방향, 네 방향 막힘, 다칸 가구, 재료 부족, 저장/로드, 멀티 충돌.
